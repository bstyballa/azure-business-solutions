# 01. Secure Azure Environment with Defender for Cloud

## 📌 Overview
This project focuses on deploying a compliant Azure cloud infrastructure, auditing security baselines with Microsoft Defender for Cloud, and remediating identified posture weaknesses to improve overall Azure Secure Score.

## 🛠️ Built With & Technologies Used
* **Microsoft Defender for Cloud** (Posture Management & Recommendations)
* **Azure Policy** (Regulatory Compliance Benchmarks)
* **Resource Groups & Virtual Machines** (Target Workloads)

## 🎯 Key Implementation Steps
1. **Security Posture Assessment:** Onboarded Azure subscription resources into Microsoft Defender for Cloud and ran an initial Secure Score analysis.
2. **Policy Assignment:** Enforced the Microsoft Cloud Security Benchmark policy initiative across target resource groups.
3. **Finding Remediation:** Resolved critical security findings, including disabling public management ports, enforcing encryption-at-rest, and enabling vulnerability assessments.
4. **Verification:** Validated Secure Score improvement and verified ongoing compliance tracking.
